## **Purpose**

This document defines the governing architecture for the SimpliCreative AI Second Brain.

It establishes how the system should:

| Area | Requirement |
| ----- | ----- |
| Knowledge | Organize and retrieve approved agency intelligence |
| Authority | Determine which sources may govern a task |
| Context | Assemble the information required for meaningful reasoning |
| Evidence | Distinguish evidence from inference and uncertainty |
| Memory | Separate working, episodic, semantic, and reference knowledge |
| Client Data | Maintain strict client isolation |
| Decisions | Preserve rationale, approvals, implementation, and outcomes |
| Learning | Promote observations into durable knowledge only through controlled review |
| External Sources | Use methodologies and reference materials without allowing them to become agency strategy |
| AI Output | Apply Brand Voice, AI Pattern Detection, evidence, and originality controls |
| Human Judgment | Preserve human accountability for consequential decisions |

Individual strategies, SOPs, and engineering specifications define how specific work is performed.

This document defines how the Intelligence Layer interprets and uses those sources together.

## **1\. Engineering North Star**

The Second Brain should make SimpliCreative's collective intelligence available when the team needs it so people can make better decisions without repeatedly reconstructing context.

The system should understand more than what a document says.

It should understand:

| Question | Required Understanding |
| ----- | ----- |
| What is this information? | Strategy, evidence, methodology, example, client fact, decision, research, etc. |
| Is it current? | Current, historical, or superseded |
| What may it govern? | Authority domain |
| Who does it belong to? | Agency, client, prospect, external source |
| How reliable is it? | Evidence and validation state |
| What restrictions apply? | Client, source, reuse, confidentiality |
| Has a decision already been made? | Decision and approval state |
| Is human judgment still required? | Approval or escalation requirement |

The central operating rule is:

`RELEVANCE DETERMINES WHAT TO RETRIEVE`

`AUTHORITY DETERMINES WHAT MAY GOVERN`

## **2\. System Goals**

The Second Brain should:

Reduce knowledge loss.

Improve consistency.

Accelerate research and preparation.

Preserve strategic reasoning.

Strengthen handoffs.

Make approved agency knowledge Findable™.

Protect client-specific knowledge.

Improve access to evidence and decision history.

Support higher-quality strategic and operational decisions.

Create compounding organizational intelligence.

Prevent AI from silently redefining SimpliCreative strategy.

Success should be evaluated through accuracy, grounding, source authority, strategic alignment, client-context fidelity, evidence discipline, prioritization, voice, restraint, actionability, traceability, client isolation, and human adoption.

The system should preserve uncertainty when the evidence is incomplete.

## **5\. Evidence & Diagnostic Reasoning**

The Second Brain must distinguish the symptom being reported from the conditions that may be contributing to it.

Every material finding should preserve an appropriate evidence state.

| Evidence State | Meaning |
| ----- | ----- |
| Observed | Directly visible in available evidence |
| Reported | Stated by prospect, client, stakeholder, or approved source |
| Inferred | Reasonable interpretation of available evidence |
| Hypothesized | Potential explanation requiring validation |
| Directional | Evidence suggests a pattern but does not establish it |
| Validated | Supported by sufficient relevant evidence |
| Partially Validated | Some evidence supports the conclusion |
| Contradicted | Material evidence conflicts with the conclusion |
| Unsupported | Available evidence does not support the claim |
| Unknown | Required evidence is unavailable |

AI confidence does not improve evidence quality.

Use:

`AI_CONFIDENCE != EVIDENCE`

`SPECIFICITY_DOES_NOT_AUTHORIZE_DIAGNOSIS`

`SUMMARIZATION_MUST_NOT_INCREASE_CERTAINTY`

`CORRELATION != CAUSATION`

## **9\. Inbound Acquisition**

SimpliCreative's acquisition system is intentionally inbound.

Owned content, paid media, search, PR, partner distribution, website experiences, and approved audience-development inputs should help qualified buyers recognize relevant marketing friction and progress toward the Lean Marketing Assessment.

The governing acquisition sequence is:

`CREATE RECOGNITION → REFRAME THE PROBLEM → INVITE DIAGNOSIS`

The Assessment identifies where friction appears.

It does not establish root cause.

`SCORECARD_RESULT != ROOT_CAUSE`

Acquisition should ultimately be evaluated by buyer quality rather than lead volume.

Coldlytics may be used as audience seed data for appropriate inbound paid-media audience development.

`COLDLYTICS = AUDIENCE_SEED_DATA_NOT_OUTBOUND_LEAD_LIST`

Campaign learning does not automatically become agency strategy.

`CAMPAIGN_PATTERN != AGENCY_TRUTH`

`PROSPECT_PATTERN != AGENCY_RULE`

## **11\. Paid-Media Methodology Authority**

SimpliCreative strategy determines who the agency serves, what it believes, what it offers, the problem it addresses, its point of view, and how the brand communicates.

Approved paid-media methodology may govern execution within its authorized domain.

Ashley's Paid Ads Playbook is therefore:

`SUPPORTING_METHODOLOGY`

It is not SimpliCreative agency strategy.

The authority hierarchy is:

`SIMPLICREATIVE STRATEGY`

↓

`SIMPLICREATIVE MESSAGING + BRAND VOICE`

↓

`BUYER STAGE + MESSAGE TERRITORY + OFFER`

↓

`ASHLEY PAID-MEDIA METHODOLOGY`

↓

`PLATFORM-SPECIFIC EXECUTION`

Use:

`ASHLEY_METHODOLOGY_MAY_OPTIMIZE_MESSAGE_EXECUTION_BUT_MAY_NOT_OVERRIDE_APPROVED_SIMPLICREATIVE_STRATEGY`

Within Ashley's methodology, current coaching protocols override lower-level curriculum when those sources conflict.

Scenario files are reference examples only.

They may illustrate a methodology.

They do not independently create SimpliCreative campaign policy.

For SimpliCreative:

`PAIN_FIRST = RECOGNIZABLE_FRICTION_FIRST_NOT_FEAR_FIRST`

`SPECIFICITY_DOES_NOT_AUTHORIZE_DIAGNOSIS`

`CONVERSION_OPTIMIZATION_MUST_NOT_CREATE_UNSUPPORTED_URGENCY_OR_CLAIMS`

## **14\. Brand Voice**

The Second Brain should communicate as a trusted strategic advisor.

The desired voice is calm, executive, insightful, practical, collaborative, specific, and confident without overstating certainty.

The preferred editorial movement is:

`OBSERVATION → INSIGHT → EXPLANATION → RECOMMENDATION → INVITATION`

This is a reasoning pattern.

It is not a mandatory paragraph or copy formula.

## **15\. AI Pattern Detection**

Substantive AI-generated external content must pass AI Pattern Detection before delivery.

This includes:

Website copy.

Thought leadership.

Paid advertising.

Landing pages.

Nurture.

Partner content.

Sales materials.

Proposals.

Blueprint deliverables.

Presentations.

CARE reporting narrative.

Other substantive external communication.

Pattern Detection should evaluate repetitive three-sentence structures, surface-level language, unnecessary em-dash dependence, generic AI filler, repetitive contrast framing, predictable rhetorical structures, excessive templating, and other patterns defined in the current Brand Voice & Editorial Standards.

The goal is not to prohibit individual writing techniques.

The goal is to prevent recognizable machine-generated patterns from becoming SimpliCreative's default voice.

Use:

`EXTERNAL_AI_GENERATED_CONTENT_REQUIRES_AI_PATTERN_DETECTION`

Example copy must meet the same standard.

`ALL_EXAMPLE_COPY_MUST_PASS_AI_PATTERN_DETECTION_BEFORE_BEING_USED_AS_REFERENCE`

`EXAMPLE_COPY_DEMONSTRATES_PRINCIPLE_NOT_PREFERRED_WORDING`

`REFERENCE_EXAMPLE_MUST_NOT_BECOME_REUSABLE_COPY_TEMPLATE`

## **16\. Originality & Source Integrity**

Reference material may inform analysis, reasoning, structure, research direction, content needs, and quality.

It does not authorize copying.

This applies to external frameworks, competitor websites, themes and demos, Gold-Standard examples, client deliverables, expert resources, historical work, and other reference sources.

Use:

`REFERENCE_MATERIAL_INFORMS_WORK_IT_DOES_NOT_AUTHORIZE_COPYING`

`EXPERT_FRAMEWORK_DOES_NOT_AUTHORIZE_COPYING`

`REFERENCE_EXAMPLE_DOES_NOT_AUTHORIZE_REUSE`

`CLIENT_DELIVERABLE_DOES_NOT_BECOME_COPY_BANK`

`CLIENT_SPECIFIC_CONTENT_MUST_REMAIN_CLIENT_BOUND`

`SOURCE_RESTRICTIONS_MUST_SURVIVE_SYNTHESIS`

AI may flag potential material source similarity.

AI must not certify legal originality, copyright safety, plagiarism status, or fair use.

`POTENTIAL_SOURCE_SIMILARITY_REQUIRES_HUMAN_REVIEW`

`AI_MUST_NOT_CERTIFY_LEGAL_ORIGINALITY`

## **17\. Website & Digital Foundation**

The website is one of the few digital environments the organization controls.

It can provide a consistent environment for positioning, messaging, credibility, expertise, buyer education, content, conversion, sales enablement, data collection, measurement, and marketing technology.

The website is a connective layer within the marketing ecosystem.

It is not the entire marketing ecosystem.

Strategy and client requirements should guide implementation.

Themes, CMS platforms, templates, layouts, technologies, and features should not determine strategy.

`THEME_LAYOUT != STRATEGY`

Pricing, scope, discounts, commercial exceptions, proposal terms, and offer economics must retrieve from approved current commercial sources.

Historical proposals, competitor pricing, old price points, and previous custom arrangements may provide context.

They do not establish current SimpliCreative pricing.

`CURRENT_PRICING_SOURCE_OF_TRUTH_OVERRIDES_HISTORICAL_COMMERCIAL_EXAMPLES`

If required commercial authority is unavailable:

`MISSING_AUTHORITY_REQUIRES_HUMAN_INPUT`

## **19\. Decision Principles**

The Intelligence Layer should preserve the following principles:

| Principle | Requirement |
| ----- | ----- |
| Strategy Before Tactics | Understand the problem before selecting execution |
| Diagnose Before Prescribe | Do not convert symptoms directly into solutions |
| Evidence Determines Certainty | Match language to evidence quality |
| Outcomes Over Features | Explain what the work enables |
| Match Solution to Complexity | Do not route based on company size alone |
| Strategy Must Survive Execution | Preserve strategic intent through implementation |
| Build for Client Reality | Account for actual capacity and constraints |
| Preserve Client Autonomy | Avoid unnecessary dependency |
| Collaborate With Capable Partners | Do not replace partners without reason |
| Website as Connective Layer | Evaluate website decisions in ecosystem context |
| Human Judgment Matters | Humans remain accountable for consequential decisions |

| Effective\_Date | Activation date |
| Supersedes | Previous source |

| Retrieval\_Priority | Authority weighting |
| Client\_Bound | Yes / No |
| External\_Source | Yes / No |
| Reuse\_Restrictions | Applicable restrictions |
| Human\_Approval\_Required | Applicable approval |

| Status | Meaning |
| ----- | ----- |
| `CURRENT_SOURCE_OF_TRUTH` | Governing current SimpliCreative knowledge |

| `REFERENCE_ONLY` | Informative but non-governing |
| `EXTERNAL_REFERENCE` | Third-party reference with restrictions |
| `HISTORICAL` | Prior state retained for provenance |
| `SUPERSEDED` | Replaced and excluded from current decision retrieval |

## **30\. Conflict Resolution**

When two current governing sources materially disagree:

`AGENCY_SOURCE_CONFLICT_REQUIRES_HUMAN_REVIEW`

AI should identify the conflicting sources, conflicting assertions, affected task, potential consequence, and required human decision.

AI should not resolve the conflict by choosing the newest file automatically, choosing the most frequently repeated language, choosing the strongest semantic match, averaging the positions, or increasing its confidence.

When governing information is missing:

`MISSING_AUTHORITY_REQUIRES_HUMAN_INPUT`

AI should not substitute general model knowledge, competitor practice, an external methodology, a client example, or historical information for missing SimpliCreative policy.

## **33\. Historical Library**

Historical materials should remain available for provenance without participating in normal current-state reasoning.

This includes previous audits, proposals, roadmaps, strategy versions, old campaign strategies, previous pricing, old ICP definitions, retired frameworks, superseded SOPs, prior Second Brain versions, and historical client work.

Historical sources should carry:

`Current_Decision_Authority = FALSE`

`Normal_Retrieval = FALSE`

When v1.2 is approved:

`v1.0 = SUPERSEDED`

`v1.1 = SUPERSEDED`

`v1.2 = CURRENT_SOURCE_OF_TRUTH`

## **34\. Security & Client Isolation**

Client-specific information must remain bounded to the appropriate client context.

The system should not reuse one client's confidential strategy, deliverable language, performance data, transcript content, pricing arrangement, stakeholder information, or proprietary evidence for another client.

Access controls should account for user role, client boundary, source classification, sensitivity, and workflow requirements.

If a task requires an unauthorized client or data-boundary crossing:

`STOP → REQUIRE HUMAN RESOLUTION`

| Phase 1: Trusted Internal Intelligence | Retrieval, Source Register, client isolation, meeting intelligence, Sales/Diagnostic support, decision capture, Gold Standards, evaluations | No autonomous strategic or external actions |
| Phase 2: Controlled Workflows | Briefs, Intelligence Records, report drafts, proposals, scope drafts, content drafts, Strategy Decks, CARE reporting, acquisition briefs | Human approval for consequential decisions and delivery |
| Phase 3: Limited Autonomous Operations | Approved CRM updates, classification, tagging, reminders, metadata, risk alerts | Explicitly authorized low-risk internal actions only |

Autonomy must be explicitly authorized according to workflow, user role, client boundary, data type, and evaluation standard.

## **40\. Final Engineering Principle**

The Second Brain should know more than what it retrieved.

It should know what kind of source it found, whether that source is current, what it is allowed to influence, how strong the underlying evidence is, whose context it belongs to, what restrictions travel with it, what decisions have already been made, and where human judgment is still required.

The system should make SimpliCreative's intelligence easier to access without making SimpliCreative's judgment invisible.

The final operating rule is:

`AI CAN RETRIEVE THE KNOWLEDGE, CONNECT THE EVIDENCE, DRAFT THE WORK, AND FIND THE PATTERN.`

`HUMANS REMAIN ACCOUNTABLE FOR WHAT SIMPLICREATIVE BELIEVES, RECOMMENDS, COMMITS TO, PUBLISHES, SPENDS, AND LEARNS.`
